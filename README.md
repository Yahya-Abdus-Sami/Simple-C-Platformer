This is a Platformer game written in C and Raylib for my programming fundamentals (PF) course at university.

A player must avoid incoming arrows and collect the stars to continue playing and build up their score.


This project is the final project for the PF lAB course that is meant to display a clear implementation and understanding of core progrmming concepts covered in the course.
In this game, the player controls a sprite, a blue ball, the sprite can move 
right or left and can jump/double-jump to interact with platforms. 

The objective of this game is to collect as many stars as possible while 
avoiding arrows that travel across the screen getting progressively more 
difficult as the player collects more stars.

Although simple, this game demonstrates proper understanding and active 
application of simple game physics such as inputs, collisions and also 
including Raylib vectors, acceleration and gravity. 
Moreover, the game also demonstrates a solid foundation of programming 
knowledge including concepts like functions, structs, logical and arithmetic 
operations, iterations, and file handling and understanding game 
development libraries like Raylib. It also follows a Modular programming 
approach with the main problem divided into 8 different subroutines.

technologies used: Raylib and C as well as Piskal for making sprites.
